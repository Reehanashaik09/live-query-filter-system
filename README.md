# Live Query Filter System

A full-stack web application featuring a debounced search input, multi-category filtering, and paginated grid layouts built with Node.js, Express, and React.

## Project Structure
- `/server` - Backend API (Express)
- `/client` - Frontend UI (React / Vite)

## Getting Started Locally

### 1. Run the Backend
cd server
npm install
node server.js

### 2. Run the Frontend
cd client
npm install
npm run dev
